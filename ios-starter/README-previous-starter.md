# Emi's Learning Platform — iOS starter project

This is a starter Xcode project for packaging the interactive Year 4 times-tables game as an iOS app. It bundles the game locally, so the game itself does not need an internet connection.

## What is included
- SwiftUI app shell with a local WKWebView
- Bundled `index.html` game with seven activities
- App icon placeholder

## What is still needed before App Store submission
1. Open `EmisLearningPlatform.xcodeproj` in Xcode on a Mac.
2. Select your own Apple Developer team and set a unique Bundle Identifier (the starter uses `uk.dannykehoe.emislearningplatform`, which may need changing).
3. Replace the placeholder app icon with final artwork and test on real iPhones/iPads.
4. Decide whether to add score saving, accessibility refinements, and a parent/teacher information screen. Scores currently reset when the page is reloaded.
5. Complete App Store Connect metadata, age rating, privacy details, screenshots, and any required child-directed-app disclosures.
6. Archive and upload through Xcode, then submit for Apple's review.

I cannot sign the app with your Apple account or submit it on your behalf from this environment. Apple decides whether it is accepted; a web-view wrapper alone is not a guarantee of approval.
